# Release privacy review

The distributed archive and public source files were checked for personal names,
account identifiers, user-profile paths, machine names, credential patterns and
personal Windows SIDs, including ASCII and UTF-16 strings in executables/DLLs.
No matching personal data was found. Embedded PE debug paths were inspected;
remaining paths are upstream game/project build paths, not local user paths.
Third-party copyright notices and an upstream library support address are retained.

Saves, screenshots, runtime logs, backups, local shortcuts, development evidence,
private project prompts and publishing/authentication helpers are excluded.
Public documentation uses generic installation examples and a summarized test report.
The public repository and GitHub release remain associated with their publisher's
GitHub account; that association is separate from the contents of this archive.
